# H5 Web 聊天系统 (H5 Private Web Chat)

专为移动端 H5 优化的私密 Web 群聊系统。支持管理员口令管控、不对外开放防护、文本/图片消息收发、一键复制文本、一键下载图片以及 Docker 简易容器化部署。

## 🌟 功能特性

1. **管理员独立安全页面与纯动态多房间管控**：
   - **隐藏独立路由入口**：对外公开聊天界面不暴露任何“管理员”字样，管理员通过独立安全路由 `/admin` (如 `http://localhost:7001/admin`) 登录运维。
   - **纯动态房间创建**：系统**默认无任何预置房间**，完全由管理员在后台根据需求自由创建房间（自定义 ID、名称与开启保密口令）。
   - **口令变更全员强制下线**：当管理员修改或开启了房间保密口令后，服务端会自动清除所有在线设备的口令缓存，并**强制将该房间内所有已连接的设备踢下线重置**，唯有重新输入最新正确的房间口令方可再次连接！
   - 支持在线成员纯粹查看、清空历史消息与管理员防伪密码修改。
2. **普通用户体验、重名校验与在线人员查看**：
   - **在线成员重名校验**：加入房间成功验证口令后，服务端会自动校验当前房间内是否存在同名的在线成员（不区分大小写），若发生重名将阻断加入并提醒更换昵称。
   - 聊天界面 Header 右上角精致展现**当前登录用户的【用户名与专属头像】**。
   - 普通用户点击顶部“在线 X 人”即可弹窗**查看当前房间所有在线成员列表**。
3. **全方位防爆破安全防护 (Anti-Brute-Force & Rate Limiter)**：
   - 针对管理员登录、管理员改密、房间口令鉴权全方位实施 IP/账号级的频率限制。
   - 单 IP 连续输错密码达 5 次后，系统触发**安全冷却锁**，强制锁定 5 分钟 (300秒) 并返回倒计时提醒。
   - 错误密码引入 **渐进式延时响应 (600ms)**，将自动化攻击脚本的爆破效率降低 99% 以上。
2. **不对外公开与快捷入群**：
   - 不开启口令时：只需输入“用户名”即可快捷进入聊天。
   - 开启口令时：必须同时输入正确的“用户名”和“房间口令”方可成功建立 Socket 连接。
3. **文本与图片消息收发**：
   - 支持发送长文本、表情。
   - 支持选择/拖拽上传图片消息，服务端安全存储。
4. **H5 移动端极佳交互**：
   - **文字一键复制**：每条文本消息右侧提供快捷“一键复制”图标，带 Toast 成功反馈。
   - **图片一键下载**：点击消息图片可选择在右下角直接一键保存/下载，或者全屏放大预览并下载。
   - **响应式 UI**：专为 H5 设计的高颜值暗黑玻璃拟态 (Glassmorphism) 主题，自适应 iPhone/Android 顶部与底部安全区域。
5. **Docker 容器化一键部署**：
   - 提供完整的 `Dockerfile` 与 `docker-compose.yml`，持久化挂载图片存储目录 `uploads`。

## 🛠️ 本地运行方法

### 1. 安装依赖
```bash
npm install
```

### 2. 启动服务
```bash
# 生产模式
npm start

# 开发模式 (支持热重载)
npm run dev
```

启动完成后，打开浏览器访问: [http://localhost:3000](http://localhost:3000)

## 🐳 Docker 部署方法

### 方式一：使用 Docker Compose (推荐)

在项目根目录下执行：
```bash
docker-compose up -d --build
```
服务将在后台运行，并自动挂载持久化存储数据卷 `chat_uploads` 保存图片。访问地址: `http://宿主机IP:3000`

### 方式二：手动 Docker 命令构建与运行

1. **构建镜像**：
   ```bash
   docker build -t h5-web-chat .
   ```

2. **运行容器**：
   ```bash
   docker run -d \
     --name h5_web_chat \
     -p 7001:3000 \
     -e ADMIN_PASSWORD=admin123 \
     -e REQUIRE_ROOM_CODE=true \
     -e INITIAL_ROOM_CODE=8888 \
     -v chat_uploads:/app/public/uploads \
     h5-web-chat
   ```

## ⚙️ 环境变量配置说明

| 环境变量 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `PORT` | `3000` | 服务运行端口 |
| `ADMIN_PASSWORD` | `admin123` | 管理员控制台初始登录密码 |
| `REQUIRE_ROOM_CODE` | `false` | 是否初始开启房间口令要求 (`true`/`false`) |
| `INITIAL_ROOM_CODE` | `8888` | 初始房间口令内容 |
